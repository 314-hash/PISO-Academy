# Maligayang Pagdating sa PISO Academy Documentation

**PISO Academy** is the official open-source developer documentation, tutorial cookbook, and interactive learning hub for **PISO Chain** (Chain ID: `2026001`).

Whether you are a student building your first token, a software engineer transitioning to Web3, or a seasoned developer architecting decentralized AI protocols, this documentation will guide you through the complete lifecycle:

$$\text{Learn} \longrightarrow \text{Code} \longrightarrow \text{Build} \longrightarrow \text{Test} \longrightarrow \text{Deploy} \longrightarrow \text{Verify}$$

---

## ⚡ Quick Network Reference

Connect your wallet or toolchain to PISO Chain Devnet:

| Parameter | Value |
| :--- | :--- |
| **Network Name** | PISO Chain Devnet |
| **Chain ID** | `2026001` (Hex: `0x1EE349`) |
| **Currency Symbol** | `PISO` (₱) |
| **RPC Endpoint (HTTP)** | `https://piso-rpc-dev.loca.lt` |
| **Local RPC Fallback** | `http://127.0.0.1:8545` |
| **Block Explorer** | [https://piso-blockchain.vercel.app/explorer](https://piso-blockchain.vercel.app/explorer) |
| **Faucet** | [https://piso-blockchain.vercel.app/](https://piso-blockchain.vercel.app/) |
| **Block Time** | 3.0 Seconds |
