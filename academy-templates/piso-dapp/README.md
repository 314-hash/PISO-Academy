# Starter Template: Full-Stack PISO dApp (Scaffold-ETH 2 Style)

Complete modern frontend + Web3 integration boilerplate for PISO Chain.

## Tech Stack
- **Framework**: Vite + React 18 + TypeScript
- **Styling**: Tailwind CSS (60-30-10 palette)
- **Web3**: Viem + Wagmi + RainbowKit
- **Network**: PISO Chain Devnet (`chainId: 2026001`)

## Running Locally
```bash
npm install
npm run dev
```
Open `http://localhost:5173` in your browser.
